# FocusStreak

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
포모도로 집중 타이머로 하루 집중시간을 기록하고, 주간 집중 리포트는 광고 시청 후 확인하는 습관형 생산성 미니앱

## Problem
원격·재택근무와 자기주도 학습이 늘면서 집중력 관리 도구 수요가 커졌지만, 앱인토스에는 뽀모도로류 생산성 타이머가 전혀 없어 WeChat 등 해외 슈퍼앱 대비 공백 카테고리로 남아있음

## Target Users
재택근무 직장인, 수험생·취준생, 프리랜서 등 20~30대 자기관리 지향 유저 (토스 3000만 유저 중 소규모 니치층 추정)

## Core Features
1. 포모도로 타이머(25/5분 커스텀)
2. 집중 스트릭 캘린더
3. 리워드 광고 시청 후 주간 집중 리포트 열람
4. 집중 세션별 태그(공부/업무/운동) 기록
5. 친구와 집중시간 비교 랭킹(로컬 공유)
6. 목표 집중시간 달성 시 배지 획득

## Monetization
- Model: ads
- Estimated MRR: $286
- Reasoning: DAU 4,000명 가정 시 리워드 광고(전환율 20%)와 배너 광고를 결합해 월 약 38.6만원(수수료 15% 반영) 순수익 추정. 다만 과거 유사 유틸리티 카테고리 13개 앱 전부 수익 0원이었던 이력을 고려하면 DAU 확보 전까지는 수익이 매우 불안정할 수 있음
